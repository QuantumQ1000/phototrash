# phototrash

Простой GUI-инструмент для Windows, который помогает находить кандидатов на удаление
(скриншоты и серии похожих фото). Устройство специально сделано максимально простым:
выбираете папку → жмёте анализ → получаете список кандидатов и серии.

## Быстрый старт

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите приложение:
   ```bash
   python phototrash.py
   ```

## Что умеет

- Определяет кандидатов на удаление по простому скорингу (пропорции, контраст, яркость).
- Находит серии похожих фото (5+ снимков с похожим визуальным отпечатком).
- Показывает превью выбранного файла.
- Экспортирует отчет в JSON для ручного разбора.
